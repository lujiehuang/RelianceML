## RelianceML — Behavioral Over-Reliance Prediction Pipeline

**Python · scikit-learn · FastAPI · Feature Engineering · Model Evaluation**

Built an end-to-end ML pipeline that converts Human–LLM interaction traces into an over-reliance probability estimate. The project includes reproducible synthetic-data generation, model comparison, evaluation, serialization, and a typed inference API designed for integration with adaptive HCI systems. Synthetic labels are explicitly marked as engineering demonstration data rather than empirical findings.
